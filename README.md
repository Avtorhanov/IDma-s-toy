# IDma's toy: 

https://avtorhanov.github.io/IDma-s-toy/

Интерактивная игрушка для малышей. На экране шесть актов: звёздочки, цветочки, шарики, прятки, море и праздник. В каждом акте несколько ступенек, и в каждой малыш учится новому действию. За каждое действие он получает яркую анимацию и звук. Когда все ступеньки акта пройдены, открывается следующий акт.

## Режимы (выбираются в меню)

- **Простой**: только нажатия, по 2 ступеньки в акте.
- **Развивающий**: по 3 ступеньки в акте, от простого к сложному.
  - Звёздочки: нажать на всё → нажать ту, что подмигнула → поймать летающие звёздочки.
  - Цветочки: нажать → держать палец, пока лейка поливает росток → отнести бабочку к цветку её цвета.
  - Шарики: нажать → держать, чтобы надуть шарик → поймать летающие шарики.
  - Прятки: нажать → найти, в какой из двух кустов спрятался зверёк → то же с тремя кустами.
  - Море: нажать → отвести рыбку в её ракушку → выбрать ракушку нужного цвета из двух.
  - Праздник: нажать → задуть или зажечь свечку, над которой искрится звёздочка (на экране счёт от 1 до 6) → повторить мелодию свечек.

## Что помогает малышу

- Звёздочка-подружка летает из акта в акт, показывает на нужное место и радуется успехам.
- Если малыш долго ничего не делает, ладошка показывает нужный жест: нажать, держать или тащить. Если он ошибается, подсказка приходит раньше.
- Ошибиться нельзя: рыбка просто возвращается назад, пустой кустик шуршит и подсказывает, где прячется зверёк.
- Глаза у героев следят за пальцем, герои моргают, подпрыгивают и переглядываются.

## Полный экран

- Кнопка «На весь экран» в меню или кнопка в правом верхнем углу во время игры. Чтобы выйти из полного экрана, кнопку в углу нужно удерживать секунду. Домик в левом углу тоже нужно удерживать, чтобы малыш не вышел случайно.
- На iPhone браузер не поддерживает полный экран для страниц. Нажмите «Поделиться» → «На экран „Домой“», и игрушка будет открываться с иконки без панелей браузера.

Всё находится в одном файле `index.html`. Игрушке не нужны сборка, библиотеки и интернет (из сети подгружается только шрифт). Звуки создаются прямо в браузере.
