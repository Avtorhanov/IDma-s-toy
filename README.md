# IDma's toy: 

https://avtorhanov.github.io/IDma-s-toy/

Интерактивная игрушка для малышей. На экране шесть актов. В каждом есть свои места, на которые нужно нажать: тогда появляются яркие анимации и звуки. Когда все места акта нажаты, открывается следующий акт.

Всё находится в одном файле `index.html`. Игрушке не нужны сборка, библиотеки и интернет (из сети подгружается только шрифт). Звуки создаются прямо в браузере.
