# IDma's toy: 

https://avtorhanov.github.io/IDma-s-toy/

Интерактивная игрушка для малышей. На экране шесть актов. В каждом есть свои места, на которые нужно нажать: тогда появляются яркие анимации и звуки. Когда все места акта нажаты, открывается следующий акт.

Всё находится в одном файле `index.html`. Игрушке не нужны сборка, библиотеки и интернет (из сети подгружается только шрифт). Звуки создаются прямо в браузере.

## Акты

1. **Звёздочки.** Пять спящих звёзд загораются и улыбаются. В конце просыпается луна и пролетают кометы.
2. **Цветочки.** Бутоны распускаются, из каждого цветка вылетает бабочка. В конце появляется радуга.
3. **Шарики.** Шары лопаются с конфетти, из каждого выпадает зверёк.
4. **Прятки.** Из кустиков выскакивают зайчик, ёжик, лиса и мишка.
5. **Море.** Ракушки раскрываются, в них жемчужины, из каждой выплывает рыбка. В конце проплывает кит.
6. **Праздник.** Нужно зажечь свечки на торте и открыть подарки. В конце салют и мелодия.

## Для малыша

- Если ребёнок долго ничего не нажимает, нужные места мигают кольцами-подсказками.
- Нажатие мимо цели тоже отзывается: звёздочкой, пузырьками или искрами.
- Открытые цветы, зверята и рыбки откликаются на повторные нажатия.

## Для родителей

- На стартовом экране можно выбрать, с какого акта начать, выключить звук и открыть игру на весь экран.
- Вернуться в меню во время игры можно, только удерживая домик в углу экрана одну секунду, чтобы ребёнок не вышел случайно.

## Как открыть

- Включите GitHub Pages: **Settings → Pages → Deploy from a branch → `main` / root**. Игрушка будет доступна по адресу `https://avtorhanov.github.io/IDma-s-toy/`.
- Добавьте её на главный экран телефона или планшета, и появится значок со звёздочкой. На iPhone и iPad: «Поделиться → На экран „Домой“». На Android: меню браузера → «Добавить на главный экран». С главного экрана игрушка открывается на весь экран, без адресной строки.
- Или скачайте папку целиком и откройте `index.html` в браузере.

Двойное нажатие и щипок не увеличивают экран, поэтому малыш может стучать по экрану сколько угодно.
